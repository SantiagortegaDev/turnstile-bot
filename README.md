## Quick Start
use **/turnstile-bot-verify**, enter the link, wait until get verify and you are now verify!
also you can check your status any time with **/turnstile-bot-status**

## Commands

- **/turnstile-bot-ping** - Check bot latency

- **/turnstile-bot-status** - Check if you have been verified with turnstile

- **/turnstile-bot-verify** - Verify you with turnstile

- **/turnstile-bot-help** - Show this help message

## Permissions

- chat:write
- commands
- app_mentions:read
- channels:history
- user
